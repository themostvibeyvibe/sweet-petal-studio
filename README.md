# Sweet Petal Studio

Create a simple, cute website with a Frutiger Aero theme (mid-2000s skeuomorphic design: glossy transparent gradients, soft light flares, bubble/water effects, pastel blue/white palette) blended with subtle cat and animal cute elements. Focus purely on visual design—no upload features or interactive media controls. Include designated placeholders for personal pictures and GIFs (clearly labeled areas where images will be added later via manual instruction). Use real photo placeholders (e.g., from Unsplash/Pexels) that show example content—never AI-generated images. Incorporate animal motifs through: paw print icons as section dividers, cat-ear accents on UI elements, simple line-art animal illustrations (from free sources like unDraw) in corners, and photo frames shaped like animal silhouettes. Ensure the design is clean, responsive, and intuitive: header with frosted-glass navbar, main gallery section for personal photos with animal-themed hover effects (non-interactive in initial build), GIF showcase area (static placeholder), and minimalist footer. Build with HTML/CSS/JS (or React) using soft shadows, glossy button finishes, and transparent overlays to capture Frutiger Aero essence while feeling warm and approachable. Avoid any technical jargon or AI references—make it feel handcrafted. The site should look complete and polished even with placeholder images, ready for the user to provide specific pictures/GIFs later for manual insertion.
